# إنفوجرافيك عمر بن الخطاب رضي الله عنه
**إعداد المعلمة: ميرفت أمين**

مشروع HTML تعليمي تفاعلي جاهز للرفع على GitHub Pages.

## الفكرة
إنفوجرافيك مبسط وجذاب للأطفال مبني على صفحات الدرس المرسلة عن عمر بن الخطاب رضي الله عنه.

## المكونات
- هيدر رئيسي بعنوان: **رحلة مع الفاروق – عمر بن الخطاب رضي الله عنه**
- اسم المعلمة: **ميرفت أمين**
- معلومات أساسية مختصرة.
- 12 فلاش كارد تفاعلية تُقلب عند الضغط.
- خط زمني يلخص محتوى الدرس من النشأة إلى الوفاة.
- لوحة "خلاصة في دقيقة".
- أسئلة اختيار من متعدد.
- أسئلة صح وخطأ.
- نشاط سحب وإدراج.
- نظام نجوم ونسبة إنجاز.
- زر لإعادة الأنشطة.
- زر انتقال إلى لعبة عمر بن الخطاب:
  https://mrsmervet.github.io/omargame/

## ملاحظة المحتوى
تم الاعتماد على المعلومات الموجودة في صور الدرس المرسلة فقط، مع تبسيط الصياغة لتناسب الأطفال.

## الملفات
- `index.html`
- `style.css`
- `app.js`
- `assets/favicon.svg`
- `.nojekyll`

## الرفع على GitHub Pages
1. فك الضغط عن ملف المشروع.
2. ارفع كل الملفات إلى جذر Repository.
3. تأكد أن `index.html` موجود في الجذر.
4. Settings → Pages.
5. اختر Deploy from a branch.
6. اختر `main` ثم `/root`.
7. Save.
